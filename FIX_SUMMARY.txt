CephFS Storage Tiering System - Critical Fixes Applied
========================================================

Date: January 12, 2026

PROBLEMS IDENTIFIED:
-------------------
1. Database inode tracking broke after migrations
   - Migration creates NEW inode (shadow file technique)
   - Database updated with OLD inode
   - Result: Database out of sync with filesystem

2. Migration was resetting last_access time
   - Database updated with last_access = NOW()
   - Files never aged properly
   - Result: Tiering logic broken

FIXES APPLIED:
--------------
1. Inode Tracking Fix (migration_worker.py):
   - Get new inode after migration: os.stat(file).st_ino
   - Delete old inode entry from database
   - Insert new inode entry with correct pool
   
   Result: Database inode matches filesystem inode after migration

2. Preserve last_access Fix (migration_worker.py):
   - Pass last_access from candidate query to migration result
   - Use preserved last_access in INSERT/UPDATE (not NOW())
   - Migration does NOT change last_access time
   
   Result: Only user access updates last_access, migrations preserve it
